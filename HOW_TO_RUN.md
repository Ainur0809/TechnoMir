# Как запустить «ТехноМир» у себя — за 5 минут

Гайд для одногруппников. Запустить базу можно, **не зная PostgreSQL** и ничего не настраивая руками. Нужны всего две программы и три команды.

## Что это

База данных интернет-магазина техники на PostgreSQL: 11 таблиц (товары, покупатели, заказы, платежи, отзывы…) с реальными моделями (Samsung, LG, Bosch), связями, ограничениями и защитой от SQL-инъекций. Всё запускается в Docker одной командой.

Не бойтесь ничего сломать: Docker всё изолирует, база в любой момент пересоздаётся с нуля. Клонируйте, поднимайте, ломайте, задавайте вопросы базе — так и учатся.

## Шаг 1. Скачать проект

```bash
git clone https://github.com/Ainur0809/TechnoMir.git
```

```bash
cd TechnoMir
```

## Шаг 2. Поднять базу одной командой

```bash
docker compose up -d
```

Docker сам скачает PostgreSQL, создаст базу `shop`, создаст 11 таблиц и зальёт данные.
Первый запуск качает образ ~минуту, потом поднимается мгновенно.

## Шаг 3. Проверить, что всё живое

Считаем товары — должно быть **60**:

```bash
docker exec technomir_db psql -U postgres -d shop -c "SELECT COUNT(*) FROM products;"
```

Увидели число — поздравляю, у вас работает база данных интернет-магазина 🎉

## Шаг 4. Посмотреть красиво (по желанию)

Поставьте **DBeaver** — бесплатный «проводник» для баз: https://dbeaver.io
Создайте новое подключение → **PostgreSQL** с такими параметрами:

| Параметр | Значение |
|---|---|
| Host | `localhost` |
| Port | **5433** |
| Database | `shop` |
| Username | `postgres` |
| Password | `postgres` |

Теперь видно все таблицы. ER-диаграмму можно построить так: правый клик на схеме `public` → **View Diagram**.

## Полезные команды

**Если что-то сломали** — сбросить базу в исходное состояние:

```bash
docker compose down -v && docker compose up -d
```

> ⚠️ Флаг `-v` удаляет все данные и пересоздаёт базу с нуля из скриптов. Это и нужно для сброса. Без `-v` данные сохраняются.

**Выключить базу, когда наигрались** (данные останутся):

```bash
docker compose down
```

**Включить снова:**

```bash
docker compose up -d
```

**Открыть базу в терминале** (интерактивный psql):

```bash
docker exec -it technomir_db psql -U postgres -d shop
```

Выйти из psql — команда `\q`.

## Если не работает

- **«Cannot connect to the Docker daemon»** — не запущен Docker Desktop. Откройте приложение и подождите, пока иконка-кит перестанет мигать.
- **«port 5433 already in use»** — порт занят другим процессом. Поменяйте в `docker-compose.yml` строку `"5433:5432"` на, например, `"5434:5432"` и подключайтесь к порту 5434.
- **Таблиц нет / данные старые** — база не пересоздалась. Выполните `docker compose down -v && docker compose up -d`.
- **`docker compose` не найдено** — старая версия Docker. Попробуйте `docker-compose` (через дефис).
